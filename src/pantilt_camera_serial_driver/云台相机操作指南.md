# 云台相机操作指南

本文档汇总了 `pantiltcamera_ready.launch` 一键启动流程与 `pantilt_tool.py` 控制工具的使用方法。

---

## 一、一键启动：pantiltcamera_ready.launch

### 功能特点

- **自动检测摄像头**：启动时自动扫描 `/dev/v4l/by-path`，选取第一个有效的 `*-video-index0` 设备，无需手动填写路径
- **自动探测云台串口**：启动时自动扫描 `/dev/ttyUSB*`、`/dev/ttyACM*`，通过发送云台协议查询命令验证响应，自动定位正确的串口
- **自动回正**：启动后自动发送 `BackToCenter` 命令，并等待云台回到零位
- **自检机制**：自动检测相机图像流、云台角度反馈、控制服务是否全部正常
- **屏蔽刷屏日志**：自动过滤 `Corrupt JPEG data` 等底层库警告，保持终端输出整洁
- **统一命名空间**：节点名固定为 `pantilt_demo` / `cv_camera_demo`，与 `pantilt_tool.py` 默认参数一致

### 启动命令

```bash
# 全自动模式（推荐）— 摄像头和串口均自动检测
roslaunch pantilt_camera_serial pantiltcamera_ready.launch

# 只指定摄像头，串口自动探测
roslaunch pantilt_camera_serial pantiltcamera_ready.launch device_path:=/dev/video2

# 只指定串口，摄像头自动检测
roslaunch pantilt_camera_serial pantiltcamera_ready.launch port_name:=/dev/ttyUSB1

# 两者都手动指定（跳过所有自动探测）
roslaunch pantilt_camera_serial pantiltcamera_ready.launch \
    device_path:=/dev/video2 \
    port_name:=/dev/ttyUSB0

# 带图像窗口和 RViz
roslaunch pantilt_camera_serial pantiltcamera_ready.launch \
    use_image_view:=true \
    use_rviz:=true

# 快速跳过回正等待（仅发送命令，不等到位）
roslaunch pantilt_camera_serial pantiltcamera_ready.launch \
    skip_center_wait:=true
```

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `device_path` | `""`（空） | 摄像头设备路径，**留空则自动检测** `/dev/v4l/by-path`；也可传 `AUTO` 或手动指定如 `/dev/video2` |
| `port_name` | `""`（空） | 云台串口路径，**留空则自动探测** `/dev/ttyUSB*`、`/dev/ttyACM*`；也可传 `AUTO` 或手动指定如 `/dev/ttyUSB0` |
| `camera_info_url` | `file://$(find cv_camera)/calibrationdata/1920x1080.yaml` | 相机标定文件路径 |
| `image_width` | `1920` | 图像宽度 |
| `image_height` | `1080` | 图像高度 |
| `rate` | `30` | 图像发布频率 |
| `use_rviz` | `false` | 是否启动 RViz |
| `use_image_view` | `false` | 是否启动图像显示窗口 |
| `timeout` | `15.0` | 自检等待超时（秒） |
| `center_timeout` | `20.0` | 回正等待超时（秒） |
| `tolerance` | `2.0` | 回正角度容差（°） |
| `skip_center_wait` | `false` | 是否跳过等待回正到位 |

### 自动检测原理

启动 `pantiltcamera_ready.launch` 时，以下脚本会在后台运行：

| 脚本 | 功能 |
|------|------|
| `resolve_device_path.py` | 扫描 `/dev/v4l/by-path`，过滤出 `*-video-index0` 主视频流设备，校验可读性后输出路径。检测到多个设备时会在终端提示候选列表。 |
| `resolve_serial_port.py` | 扫描可用串口，对每个候选串口以 `115200 8N1` 打开，发送云台 `GetPantiltPose` 查询命令，验证返回帧的 `0x55` 头、`0x12` 长度及 CRC8 校验，仅当协议握手通过才认定该串口为云台设备。 |
| `filter_jpeg.sh` | 绑定在 `cv_camera_demo` 节点上，通过 `sed` 实时过滤 stderr 中的 `Corrupt JPEG` 刷屏信息，保留其他正常错误输出。 |

## 二、控制工具：pantilt_tool.py

启动完成后，使用 `pantilt_tool.py` 进行控制和查询。

### 通用参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `-n, --ns` | `pantilt_demo` | 云台节点命名空间 |

### 子命令一览

#### 1. info — 查询云台角度状态

```bash
# 查询一次当前角度
rosrun pantilt_camera_serial pantilt_tool.py info

# 持续实时监听（按 Ctrl+C 停止）
rosrun pantilt_camera_serial pantilt_tool.py info --watch
```

#### 2. set — 设置目标角度

角度范围：
- heading（航向）：[-160°, 160°]
- roll（横滚）：[-40°, 40°]
- pitch（俯仰）：[-90°, 90°]

```bash
# 设置航向 30°，俯仰 -10°
rosrun pantilt_camera_serial pantilt_tool.py set --heading 30 --pitch -10

# 全部归零
rosrun pantilt_camera_serial pantilt_tool.py set --heading 0 --roll 0 --pitch 0
```

#### 3. center — 云台回中

```bash
rosrun pantilt_camera_serial pantilt_tool.py center
```

#### 4. mode — 切换工作模式

| 模式 | 说明 |
|------|------|
| `lock` | 完全锁定，保持当前方向不动 |
| `heading` | 航向跟随，俯仰锁定 |
| `heading_pitch` | 航向和俯仰都跟随 |
| `full_follow` | 三轴全部跟随 |

```bash
# 锁定模式
rosrun pantilt_camera_serial pantilt_tool.py mode lock

# 航向跟随
rosrun pantilt_camera_serial pantilt_tool.py mode heading

# 航向+俯仰跟随
rosrun pantilt_camera_serial pantilt_tool.py mode heading_pitch

# 全跟随
rosrun pantilt_camera_serial pantilt_tool.py mode full_follow
```

> **注意**：模式之间是直接切换的，没有"退出"某个模式的概念。例如从 `lock` 切换到 `full_follow`，直接发送 `mode full_follow` 即可。

#### 5. capture — 保存相机图像

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `-t, --topic` | `/image_color` | 图像话题 |
| `-o, --output` | `./captures` | 输出文件夹 |
| `-c, --count` | `1` | 保存张数 |
| `--interval` | `0.0` | 连续保存间隔（秒） |
| `-p, --prefix` | `capture` | 文件名前缀 |

```bash
# 保存单张图片到默认目录
rosrun pantilt_camera_serial pantilt_tool.py capture

# 指定话题和输出目录
rosrun pantilt_camera_serial pantilt_tool.py capture \
    -t /image_color \
    -o ~/Desktop/pics

# 连续保存 5 张，间隔 1 秒
rosrun pantilt_camera_serial pantilt_tool.py capture -c 5 --interval 1 -o ./images
```

文件名格式：`capture_YYYYMMDD_HHMMSS_mmm.jpg`

## 三、节点与话题对照表

| 启动文件 | 相机节点 | 云台节点 | 图像话题 | 角度话题 | 控制服务 |
|----------|----------|----------|----------|----------|----------|
| `pantiltcamera_ready.launch` | `cv_camera_demo` | `pantilt_demo` | `/cv_camera_demo/image_raw` | `/pantilt_demo/pantilt_angle_info` | `/pantilt_demo/send_command` |
| `demo_test.launch` | `cv_camera_demo` | `pantilt_demo` | `/cv_camera_demo/image_raw` | `/pantilt_demo/pantilt_angle_info` | `/pantilt_demo/send_command` |
| `pantiltcamera.launch` | `cv_camera0` | `pantilt_camera_serial0` | `/cv_camera0/image_raw` | `/pantilt_camera_serial0/pantilt_angle_info` | `/pantilt_camera_serial0/send_command` |
| `test_pantilt_only.launch` | — | `pantilt_test` | — | `/pantilt_test/pantilt_angle_info` | `/pantilt_test/send_command` |

> `pantilt_tool.py` 默认使用 `pantilt_demo` 命名空间，与 `pantiltcamera_ready.launch` 完全匹配，无需额外指定 `-n`。

## 四、快速参考

### 启动系统
```bash
roslaunch pantilt_camera_serial pantiltcamera_ready.launch
```

### 查看角度
```bash
rosrun pantilt_camera_serial pantilt_tool.py info
```

### 设置角度
```bash
rosrun pantilt_camera_serial pantilt_tool.py set --heading 0 --roll 0 --pitch 0
```

### 回中
```bash
rosrun pantilt_camera_serial pantilt_tool.py center
```

```bash
rosrun pantilt_camera_serial pantilt_tool.py capture -o ./pics
```

```bash
  x: 0.0
```

## 五、常见问题

### 1. 设备权限不足
```bash
sudo usermod -a -G dialout $USER
sudo chmod a+rw /dev/ttyUSB0
sudo chmod a+rw /dev/video0
```

### 2. 串口断开
云台串口断开后需要重启 launch 文件恢复连接。

### 3. pantilt_tool.py 提示找不到服务
请确认 launch 文件已正确启动，且 `-n` 参数与节点命名空间一致。

### 4. capture 保存失败
请确认图像话题存在：
```bash
rostopic list | grep image
```

### 5. 自动检测未找到摄像头
```bash
# 检查系统是否识别到视频设备
ls /dev/v4l/by-path
# 如果没有输出，请检查 USB 连接和摄像头供电
```

### 6. 自动探测未找到云台串口
```bash
# 检查系统是否识别到串口设备
ls /dev/ttyUSB* /dev/ttyACM*
# 如果存在多个串口设备但探测均失败，可能是其他串口占用了 ttyUSB0
# 此时 launch 会自动扫描并定位到正确的串口；若仍失败，可手动指定 port_name
```

### 7. 终端仍有 Corrupt JPEG 刷屏
`pantiltcamera_ready.launch` 已内置 `filter_jpeg.sh` 过滤该警告。如果仍出现，请确认使用的是最新版 launch 文件，或检查是否通过其他方式（如直接运行 `cv_camera_node`）启动了相机节点。
